# Personal Site

My personal site — built as a learning project to go from React fundamentals to a full-stack, AI-integrated web app.

## Overview

A single-author personal site with a home page (bio, featured projects) and a blog. Currently running on hardcoded data as I work through each stage of the build; database, auth, and AI features are being added incrementally.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Markdown rendering:** react-markdown (for blog post content)
- **Deployment:** Vercel

## Features

- Home page with bio and featured projects (currently hardcoded)
- Blog with a post list and individual post pages (`/blog/[slug]`)
- Markdown-based post content
